# Routing Outline
- / = landing (positioning + top toppers + free funnel).
- /upsc-topper/[slug] = entity page per topper.
- /content/[slug] = strategy & analysis articles.
- /free-materials/[slug] = free download hubs.
- /store = compilations.
- /store/success + /api/webhook = commerce handshake.
- /admin* = protected management surfaces.

## Notes
Entity/marketing use path segments that read naturally and are stable for
SEO. Free materials live under /free-materials to keep them distinct from
paid /store.
