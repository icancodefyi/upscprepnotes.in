# Content vs Entity Pages
- Entity pages: one topper (stable, factual, structured data, can be indexed).
- Content pages: strategy/analysis/magazines (fresh, article-schema, link hubs).
- Subject pages: optional/GS-card navigation (dimensional lists, not thin pages).

## Guardrail
Avoid thin duplicate pages that compete with each other for one keyword. Each
URL should earn one primary keyword cluster.
