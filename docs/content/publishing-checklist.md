# Publishing Checklist

## Before publish
- [ ] Facts/marks traced to a verifiable source.
- [ ] No placeholder data or fabricated links.
- [ ] One primary topic; length matched to intent.
- [ ] Title = query intent; meta ≤160 chars.
- [ ] Internal links to topper/answer-copy pages.
- [ ] Schema (Article / FAQ / HowTo) where applicable.

## After publish
- [ ] Sitemap updated.
- [ ] Index summary posted to sprint log.
- [ ] Analytics event verified (page_view fires).
