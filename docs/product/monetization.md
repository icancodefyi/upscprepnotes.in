# Monetization Analysis

## Model
Freemium: free single downloads (email-gated) + paid curated compilations.

## Compilation = value-added, not re-bundle
- Curation across toppers (single coherent pack).
- Annotated strategy callouts.
- Structured, searchable format.

## Price signals (from market)
- Single compilations ₹99–₹299; flagship bundles ₹149–₹199. Kept GST-inclusive.
- Bundle unions (e.g., All Strategy Reports) priced above single items.

## Tie-back
Any paid item must be justifiable vs. freely available content; otherwise it
erodes the 'verified/honest' positioning.
