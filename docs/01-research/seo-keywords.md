# SEO Keyword Clusters

## Top intent clusters (for planning)
1. Topper answer copies ("[name] answer copy pdf") — greatest demand.
2. Topper names / marksheets ("[name] marksheet", "[name] rank").
3. Strategy ("how to score 120+ in GS3").
4. Optional subject analysis ("best optional for UPSC").
5. Current affairs / magazines.

## Planned content surface
- Directed answer-copy + marksheet pages per topper (entity pages).
- Subject scoring analysis pages.
- Paper-wise strategy hubs.
- Monthly current affairs.

## Note
Demand is dominated by topper-focused discovery queries; build the surface
around entity pages first, then strategy, then magazines.
