# Answer Copy Verification Workflow

## Definition of "verified"
A PDF is VERIFIED only when:
1. Author attribution matches a confirmed topper (name + rank + year).
2. Source is a public, reachable URL (HTTP 200) — no fabricated links.
3. File content sampled to confirm it is the actual answer booklet.

## Process
1. Source candidate URL from public channels (UPSC allotment pages, coaching
   PDFs, Telegram archives, aspirant blogs).
2. Download + sample-check content.
3. Record source URL + verified date in inventory.
4. Mark inventory status = verified only after all three checks pass.

## Hard rule
Never publish or fulfill a copy we cannot verify. A wrong link damages trust
and rankings more than a missing one.
