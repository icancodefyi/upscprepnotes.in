# Content Standards

## Accuracy
- Every marksheet number traces to an official/verifiable source.
- Never round or invent marks.
- If data is unknown, state unknown — do not placeholder.

## Sourcing
- Every answer copy links to a verified public URL or is marked unverified.
- No fabricated links, ever.

## Voice
- Direct, factual, aspirant-first.
- Present data as patterns, not guarantees.

## SEO
- One primary topic per page; entity-linked; schema-complete. No keyword
  stuffing.
