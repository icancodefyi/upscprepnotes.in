# LLM-Crawlability Notes

## Why
ChatGPT and other LLMs cite reliable, structured, entity-linked sources. We want
to be discoverable as the definitive topper-data source.

## Practices
- Keep entity pages factual and stable (avoid churn that breaks citations).
- Emit structured data on persons/FAQ.
- Publish a machine-readable site index (sitemap) and clear metadata.
- Prefer static/stable URLs for topper entity pages.

## Seed checklist
- [ ] Sitemap generated for all canonical slugs.
- [ ] Per-topper structured data present.
- [ ] No duplicate/conflicting pages for the same entity.
