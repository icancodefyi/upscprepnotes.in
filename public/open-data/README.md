# UPSC CSE Topper Marks — Open Dataset

This dataset contains verified marks of UPSC Civil Services Examination toppers, sourced from official UPSC results and topper interviews.

Data sourced from [UPSCPrepNotes.in](https://upscprepnotes.in). Full analysis at [upscprepnotes.in/upsc-syllabus](https://upscprepnotes.in/upsc-syllabus).

## Schema

| Column | Type | Description |
|--------|------|-------------|
| firstName | string | Topper's first name |
| lastName | string | Topper's last name |
| rank | int | UPSC CSE rank |
| year | int | Examination year |
| optionalSubject | string | Optional subject chosen |
| essay | int | Essay marks (out of 250) |
| gs1 | int | GS Paper 1 marks (out of 250) |
| gs2 | int | GS Paper 2 marks (out of 250) |
| gs3 | int | GS Paper 3 marks (out of 250) |
| gs4 | int | GS Paper 4 marks (out of 250) |
| optional1 | int | Optional Paper 1 marks |
| optional2 | int | Optional Paper 2 marks |
| written | int | Total written marks |
| interview | int | Interview/personality test marks |
| total | int | Final total marks |
| slug | string | Profile slug on UPSCPrepNotes |
